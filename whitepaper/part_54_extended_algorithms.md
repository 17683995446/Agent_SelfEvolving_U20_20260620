## 54.2 贝叶斯优化

### 54.2.1 基本原理

贝叶斯优化是一种高效的全局优化方法，特别适用于评估代价高的黑盒函数优化问题。

核心思想：
1. 使用高斯过程（GP）作为目标函数的先验模型
2. 通过采集函数（Acquisition Function）平衡探索和利用
3. 迭代更新模型，逐步逼近最优解

数学框架：

目标：找到x* = argmax_{x ∈ X} f(x)

其中f是未知的、评估代价高的目标函数。

### 54.2.2 高斯过程回归

高斯过程定义：高斯过程是随机变量的集合，其中任意有限个随机变量的联合分布都是多元高斯分布。

均值函数：m(x) = E[f(x)]

协方差函数（核函数）：k(x, x') = E[(f(x) - m(x))(f(x') - m(x'))]

常用核函数：

径向基函数（RBF）：

k(x, x') = σ² exp(-||x - x'||² / (2l²))

Matérn核：

k(x, x') = σ² (2^{1-ν}/Γ(ν)) (√(2ν)||x-x'||/l)^ν K_ν(√(2ν)||x-x'||/l)

预测分布：

给定观测数据D = {(x_i, y_i)}_{i=1}^n，在测试点x*处的预测：

f(x*) | D ~ N(μ(x*), σ²(x*))

其中：

μ(x*) = k(x*, X) K^{-1} y
σ²(x*) = k(x*, x*) - k(x*, X) K^{-1} k(X, x*)

### 54.2.3 采集函数

采集函数指导下一个采样点的选择。

期望改进（Expected Improvement, EI）：

EI(x) = E[max(f(x) - f(x^+), 0)]

其中x^+是当前最优观测点。

上置信界（Upper Confidence Bound, UCB）：

UCB(x) = μ(x) + κσ(x)

其中κ控制探索和利用的平衡。

概率改进（Probability of Improvement, PI）：

PI(x) = P(f(x) > f(x^+) + ξ)

### 54.2.4 在Agent系统中的应用

贝叶斯优化可用于：
1. 超参数优化：优化模型超参数
2. 探索策略优化：优化探索-利用平衡参数
3. 资源分配：优化计算资源分配

## 54.3 元学习

### 54.3.1 元学习概述

元学习（Meta-Learning）或"学会学习"，旨在让模型学会如何快速适应新任务。

分类：
1. 基于优化的元学习：学习一个好的初始化参数
2. 基于度量的元学习：学习一个好的距离度量
3. 基于记忆的元学习：利用外部记忆存储知识

### 54.3.2 MAML算法

模型无关元学习（Model-Agnostic Meta-Learning, MAML）通过元训练找到一个对梯度更新敏感的初始化参数。

算法步骤：

1. 采样任务批次{T_i}
2. 对每个任务T_i：
   a. 在支持集上计算梯度：g_i = ∇_θ L_{T_i}(f_θ)
   b. 更新参数：θ_i' = θ - α g_i
3. 在查询集上计算元梯度：∇_θ Σ_{T_i} L_{T_i}(f_{θ_i'})
4. 更新元参数：θ = θ - β ∇_θ Σ_{T_i} L_{T_i}(f_{θ_i'})

### 54.3.3 在Agent系统中的应用

元学习使Agent能够快速适应新环境：
1. 快速适应新类型的任务
2. 快速学习新环境模式
3. 迁移已有知识到新场景

## 54.4 因果发现算法

### 54.4.1 Granger因果检验

Granger因果检验判断时间序列X是否有助于预测时间序列Y。

定义：X Granger-导致Y，如果利用X的过去值可以显著提高对Y的预测精度。

检验方法：
1. 建立受限模型：只用Y的过去值预测Y
2. 建立非受限模型：用X和Y的过去值预测Y
3. 比较两个模型的预测误差
4. 使用F检验判断差异是否显著

### 54.4.2 PC算法

PC算法（Peter-Clark算法）基于条件独立性检验发现因果结构。

算法步骤：

1. 骨架学习：
   a. 构建完全无向图
   b. 对于每对变量(X, Y)，检验条件独立性
   c. 如果存在条件集Z使得X ⊥ Y | Z，则删除边X-Y
   d. 记录分离集

2. V-结构定向：
   a. 对于非邻接变量X和Y，有共同邻居Z
   b. 如果Z不在X和Y的分离集中
   c. 则定向为X → Z ← Y

3. 规则定向：
   a. 避免产生新的V-结构
   b. 避免产生有向环
   c. 尽可能多地定向边

### 54.4.3 在Agent系统中的应用

因果发现用于：
1. 识别环境变量间的因果关系
2. 构建因果预测模型
3. 理解干预效果
4. 生成因果解释

## 54.5 异常检测算法

### 54.5.1 统计方法

Z-score方法：

z = (x - μ) / σ

如果|z| > threshold，则判定为异常。

IQR方法：

IQR = Q3 - Q1

异常边界：[Q1 - 1.5×IQR, Q3 + 1.5×IQR]

### 54.5.2 基于距离的方法

孤立森林（Isolation Forest）：

原理：异常点更容易被孤立。

算法：
1. 随机选择特征
2. 随机选择分割值
3. 递归分割直到所有点被孤立
4. 异常点的平均路径长度较短

局部异常因子（Local Outlier Factor, LOF）：

LOF衡量点相对于其邻居的局部密度偏差。

计算：
1. k-距离：到第k近邻居的距离
2. 可达距离：max(k-距离, 实际距离)
3. 局部可达密度：1 / 平均可达距离
4. LOF：邻居局部可达密度与自身局部可达密度的比值

### 54.5.3 基于重构的方法

自编码器异常检测：

原理：正常数据可以被良好重构，异常数据重构误差大。

方法：
1. 训练自编码器学习正常数据的压缩表示
2. 计算重构误差
3. 重构误差超过阈值则判定为异常

变分自编码器（VAE）扩展：

利用重构概率而非重构误差，更加稳定。

### 54.5.4 在Agent系统中的应用

异常检测用于：
1. 环境异常识别：检测系统状态异常
2. 预测异常检测：检测预测结果的异常
3. 行为异常检测：检测Agent自身行为的异常
4. 安全威胁识别：识别潜在的安全威胁

## 54.6 时间序列分解

### 54.6.1 经典分解

时间序列分解将序列分解为趋势、季节性和残差成分。

加法模型：

Y(t) = T(t) + S(t) + R(t)

乘法模型：

Y(t) = T(t) × S(t) × R(t)

分解步骤：
1. 估计趋势（移动平均或回归）
2. 去趋势：Y(t) - T(t)
3. 估计季节性（周期平均）
4. 计算残差

### 54.6.2 STL分解

STL（Seasonal and Trend decomposition using Loess）使用局部加权回归进行分解。

特点：
1. 可以处理任何类型的季节性
2. 趋势和季节性的平滑度可控
3. 对异常值鲁棒

算法步骤：
1. 内循环：更新季节性和趋势
   a. 去趋势
   b. 周期子序列平滑
   c. 季节性后平滑
   d. 去季节化
   e. 趋势平滑
2. 外循环：计算鲁棒权重

### 54.6.3 在Agent系统中的应用

时间序列分解用于：
1. 趋势预测：提取长期趋势进行预测
2. 季节性处理：识别和处理周期性模式
3. 异常检测：在残差中检测异常
4. 特征提取：提取分解成分作为特征

## 54.8 模型压缩与加速

### 54.8.1 知识蒸馏

知识蒸馏将大模型（教师）的知识传递给小模型（学生）。

方法：
1. 训练大教师模型
2. 使用软标签训练学生模型

软标签：

q_i = exp(z_i/T) / Σ_j exp(z_j/T)

其中T是温度参数，控制软标签的平滑度。

损失函数：

L = α L_hard + (1-α) L_soft

### 54.8.2 量化

量化将模型权重从高精度（如32位浮点）转换为低精度（如8位整数）。

方法：
1. 训练后量化：直接量化训练好的模型
2. 量化感知训练：在训练中模拟量化

量化类型：
- 权重量化：只量化权重
- 激活量化：同时量化激活
- 全量化：所有权值和激活都量化

### 54.8.3 剪枝

剪枝删除模型中不重要的权重或神经元。

方法：
1. 非结构化剪枝：删除单个权重
2. 结构化剪枝：删除整个滤波器或通道

重要性度量：
- 基于幅值：|w| < threshold
- 基于梯度：|∂L/∂w| small
- 基于Hessian：考虑二阶信息

### 54.8.4 在Agent系统中的应用

模型压缩用于：
1. 减少内存占用
2. 加速推理速度
3. 降低能耗
4. 支持边缘部署

## 54.9 联邦学习

### 54.9.1 基本原理

联邦学习允许多个参与方在不共享原始数据的情况下协作训练模型。

框架：
1. 中央服务器分发全局模型
2. 各参与方在本地数据上训练
3. 上传模型更新（而非数据）
4. 服务器聚合更新
5. 重复直到收敛

### 54.9.2 聚合算法

FedAvg算法：

w_{t+1} = Σ_{k=1}^K (n_k/n) w_{t+1}^k

其中n_k是第k个参与方的样本数，n是总样本数。

FedProx算法：

添加近端项限制本地更新的幅度：

min_w L_k(w) + (μ/2)||w - w_t||²

### 54.9.3 隐私保护

差分隐私：

在模型更新中添加噪声，提供数学隐私保证。

安全聚合：

使用密码学技术保护聚合过程中的隐私。

### 54.9.4 在Agent系统中的应用

联邦学习可用于：
1. 多Agent协作学习
2. 知识共享而不泄露敏感信息
3. 分布式模型训练
4. 隐私保护的数据利用

## 54.10 神经架构搜索

### 54.10.1 基本原理

神经架构搜索（NAS）自动设计神经网络架构。

搜索空间：
- 层类型（卷积、池化、全连接等）
- 层参数（通道数、核大小等）
- 连接方式（顺序、跳跃等）

搜索策略：
- 随机搜索
- 强化学习
- 进化算法
- 梯度优化（可微分NAS）

### 54.10.2 可微分NAS

DARTS（Differentiable Architecture Search）：

将离散的架构选择松弛为连续的权重：

α = softmax(α_raw)

混合操作：

ō(x) = Σ_{i=1}^N α_i o_i(x)

交替优化架构权重α和网络权重w。

### 54.10.3 在Agent系统中的应用

NAS可用于：
1. 自动设计预测模型架构
2. 适应不同任务的模型结构
3. 优化模型效率和精度的平衡
4. 持续进化模型结构

## 54.11 强化学习高级算法

### 54.11.1 软演员-评论家（SAC）

SAC是最大熵强化学习框架下的off-policy算法。

目标：最大化累积奖励和策略熵：

J(π) = E[Σ_t r(s_t, a_t) + α H(π(·|s_t))]

关键组件：
1. 演员网络：输出动作分布
2. 评论家网络：估计Q值
3. 温度参数α：自动调整

### 54.11.2 近端策略优化（PPO）

PPO通过限制策略更新幅度提高稳定性。

目标函数：

L^{CLIP}(θ) = E[min(r_t(θ)A_t, clip(r_t(θ), 1-ε, 1+ε)A_t)]

其中r_t(θ) = π_θ(a_t|s_t) / π_{θ_old}(a_t|s_t)

### 54.11.3 在Agent系统中的应用

强化学习用于：
1. 策略优化：优化任务选择策略
2. 资源分配：优化资源使用策略
3. 探索策略：优化探索行为
4. 长期规划：学习长期最优策略
